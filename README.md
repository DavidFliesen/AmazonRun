# Amazon Run

A starter 2D scrolling river game for GitHub Pages.

## How to play

- Arrow keys or WASD: steer the boat
- Spacebar: boost
- Collect 10 supply crates
- Avoid rocks, logs, crocodiles, and raider boats
- Survive long enough to reach the extraction point

## How to publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `game.js` to the repository root.
3. Go to **Settings → Pages**.
4. Set source to your main branch and root folder.
5. Open the published GitHub Pages link.

## Expansion ideas

- Replace drawn shapes with custom sprite art.
- Add sound effects for engine, splash, collision, and supply pickup.
- Add missions: rescue explorers, deliver medicine, recover cargo, photograph wildlife.
- Add bosses: pirate speedboat, storm surge, giant anaconda encounter.
- Add mobile touch controls.
