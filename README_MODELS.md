# Amazon Run 3D Models

This package contains actual GLB model files for Amazon Run.

## Files

- `amazon_river_boat.glb` — stylized Amazon river cargo boat
- `amazon_alligator.glb` — stylized alligator wildlife / river hazard
- `model_preview.html` — simple Three.js preview page

These are procedural game-ready models, built to be much more detailed than the original placeholder geometry while still lightweight enough for browser use.
